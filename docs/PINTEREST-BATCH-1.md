# Pinterest Batch 1: Days 6 to 15

60 pins across ten days, six a day. Every pin is written from a verified fact
in the post it links to, and every image prompt is composed individually. No
two pins share a layout, a photo treatment or a sentence structure.

**Days 1 to 5 are already uploaded** and archived in
`PINTEREST-DONE-DAYS-1-5.md`. Do not re-pin those.

| | |
|---|---|
| Pins | 60 |
| Days | 6 to 15, six per day |
| Posts covered | 30, three pins each |
| Photo-led | About 70% |
| Duplicate layouts | None |

## How to use this

Each pin has six copy blocks: title, description, alt text, board, link and the
image prompt. Paste the prompt into your image tool, then paste the other five
into Pinterest. Nothing needs filling in.

The three pins for one post are spaced two days apart and each takes a
different angle, so the same article reaches three different searchers without
looking repetitive.

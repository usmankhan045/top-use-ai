# AI Tools Site — Build Blueprint

**Audience:** US / Canada / UK
**Spine:** "Make money with AI" + AI tool reviews/comparisons
**Monetization:** Affiliate (primary) → AdSense (secondary) → own digital products (later)
**Rule:** Keep planners / printables / budgeting on your EXISTING site. Do NOT duplicate them here. Cross-link the two sites instead.
